# Marketing Automation Agency System

A multi-client, full-stack marketing automation platform powered by 27+ specialized AI agents. The system provides end-to-end B2B marketing: lead generation, cold email campaigns, LinkedIn outreach, content marketing, SEO, paid media, social media management, landing pages, video content, sales enablement, customer retention, and attribution analytics — all managed across multiple clients with fully isolated workspaces.

## Quick Start

### 1. Create a New Client

```bash
# Linux/Mac
./scripts/new-client.sh acme-corp

# Windows
scripts\new-client.bat acme-corp
```

### 2. Run Discovery

```bash
cd clients/acme-corp
ai-assistant
```

Tell the Discovery Agent:
> "Analyze https://acme-corp.com and build the company profile."

### 3. Review & Correct Profile

Review `config/discovery-report.md` and correct `config/company-profile.yaml`, especially fields marked as LOW confidence.

### 4. Bootstrap Agents

> "Start the bootstrap orchestrator. Generate all operational marketing agent files."

Wait for iterative agent generation across 7 dependency waves.

### 5. Deploy Agents

```bash
# Linux/Mac
cp agents/*.md .ai/agents/

# Windows
copy agents\*.md .ai\agents\
```

### 6. Run Daily Operations

```bash
cd clients/acme-corp
ai-assistant
```

> "Start the morning routine."

## Architecture

### Three Layers, 27+ Agents

| Layer | Agents | Purpose |
|-------|--------|---------|
| **Meta** (3) | Agent Architect, Agent Critic, Bootstrap Orchestrator | Generate and quality-check operational agents |
| **Discovery & Regional** (3) | Discovery Agent, Regional Coordinator, Regional Scout | Client onboarding and multi-language lead research |
| **Operational** (24) | Generated by Bootstrap — see full list below | Daily marketing operations across all channels |

### All 24 Operational Agents

| Category | Agents |
|----------|--------|
| **Core Orchestration** | Maestro |
| **Research & Intelligence** | Market Intelligence, Lead Researcher, Analyst, SEO Agent |
| **Lead Management** | Lead Scorer, Pipeline Tracker, ABM Coordinator |
| **Content Production** | Content Strategist, Copywriter, Landing Page Agent, Video Script Agent |
| **Outreach Channels** | Email Sequence Designer, Email Personalizer, LinkedIn Outreach Agent, Social Media Manager, Paid Media Agent |
| **Quality & Delivery** | QA Reviewer, Scheduler, Multi-Channel Orchestrator |
| **Optimization** | A/B Test Manager, Attribution Analyst |
| **Post-Sale** | Sales Enablement Agent, Retention & Growth Agent |

### Operational Pipeline (Daily)

```
Analyst → Market Intelligence → SEO Agent
→ Lead Researcher / Regional Scouts → Lead Scorer → ABM Coordinator
→ Pipeline Tracker → Content Strategist → Copywriter
→ Landing Page Agent → Video Script Agent
→ Email Sequence Designer → LinkedIn Outreach Agent
→ Email Personalizer → Social Media Manager → Paid Media Agent
→ Multi-Channel Orchestrator → QA Reviewer → Scheduler
→ A/B Test Manager → Attribution Analyst
→ Sales Enablement → Retention & Growth
```

## Multi-Language Support

Regional Scouts search for leads in 7 languages: **German** (DACH), **Italian** (Italy), **Spanish** (Spain & LATAM), **French** (France & Belgium), **Portuguese** (Portugal & Brazil), **Dutch** (Benelux), **Turkish** (Turkey). All outputs in English.

## Data Schemas (22 types)

All agents communicate through structured JSON: LeadProfile, EmailSequenceConfig, QAReviewReport, ContentBrief, PipelineStatusReport, MarketIntelReport, DailyAnalyticsReport, SendLog, RegionalStrategy, ScoutBrief, BootstrapProgress, **LinkedInOutreachSequence**, **ABTestConfig**, **LandingPageSpec**, **SEOKeywordResearch**, **ABMAccountPlan**, **SocialMediaCalendar**, **AdCampaignConfig**, **VideoScriptBrief**, **SalesEnablementAsset**, **RetentionCampaign**, **MultiChannelSequence**, **AttributionReport**.

## Critical Rules

1. Always `cd` into the client folder before running the AI assistant
2. Always `git commit` after every session — Git is the database
3. All agent outputs are in English
4. All file paths are relative to the client workspace root
5. No agent calls another directly — all coordination through Maestro or Bootstrap Orchestrator
6. QA feedback loop applies to both agent generation and content production (max 3 rounds)
7. Client data is fully isolated — no cross-client data access

## Compliance

Supports GDPR, CAN-SPAM, and KVKK. Configured per client in `company-profile.yaml`. All emails include mandatory elements (unsubscribe link, company name, physical address).
